# 101570138_COMP3123-exec04

COMP3123 Exercise 04 - Express JS application.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

or

```bash
npm start
```

## Endpoints

- `GET /hello`
- `GET /user?firstname=John&lastname=Doe`
- `POST /user/John/Doe`
- `POST /users` with a JSON array in the request body
- `GET /instruction.html`
